# ELVORIX-OSINT

500-Module OSINT Reconnaissance & Local File Forensics Suite for Kali Linux / Python 3.

## Quick Start
Run `pip install -r requirements.txt` and then start `python3 scanner.py`.

## Deep Info CLI (`deep_info.py`)
- Phone: `python3 deep_info.py phone +919876543210`
- Domain: `python3 deep_info.py domain example.com`
- IP: `python3 deep_info.py ip`
- GitHub: `python3 deep_info.py github vedansh73`
- File: `python3 deep_info.py file scanner.py`
